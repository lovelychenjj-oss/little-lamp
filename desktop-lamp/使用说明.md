# 小灯当家 Mac 0.5.6

## 更新与选择
1. 解压整个 desktop-lamp 文件夹，放在个人主目录，双击新版「安装小灯当家.command」。
2. 安装器会请求旧版正常退出，备份旧应用后安装新版到 ~/Applications/小灯当家.app。
3. 点击顶部小台灯图标，在菜单中选灯具。原有蘑菇灯、布罩灯、球形灯继续保留，共 10 款。
4. 首次切换系统外观时，按 macOS 提示允许 小灯当家 控制 System Events。

| --- | --- | --- |
| 花瓣吊灯 | 主屏右上角 | 按住拉绳往下拉，松手换档 |
| 格纹吊灯 | 主屏右上角 | 按住灯罩划一下，或在灯罩上滚动 |
| 复古搪瓷吊灯 | 主屏右上角 | 下拉流苏绳坠 |

| 奶油飞碟吊灯 | 主屏右上角 | 按住灯罩划一下，或滚动 |
| 铃兰吊灯 | 主屏右上角 | 下拉串珠绳坠 |
| 折叶落地灯 | 主屏右下角 | 下拉灯罩侧边拉绳 |

新灯具采用按已确认设计生成的透明 3D 渲染图片；并非可旋转的实时三维模型。动态拉绳由界面单独绘制，光晕随模式变化。

吊灯初始放在主屏右上角，现在可拖动到其他位置。落地灯的灯头朝左，可拖灯杆或底座移动，位置单独记忆。菜单的「重置台灯位置」恢复当前灯型的默认位置。切换灯具不改变当前光线模式。

默认窗口：原有台灯 112×140，吊灯 108×156，落地灯 144×300，单位为逻辑像素。

## 原有灯具操作
- 蘑菇灯：点击底座小旋钮。
- 布罩灯：按住拉绳向下拉，松手换档。
- 球形灯：按住球体划动或在球体上滚动，拖杆／底座移动。

拉绳和划动需约 12 像素位移才触发；每次松手切一档。连续滚轮输入按一次手势处理。轻点、向上拉绳、取消操作均不会触发。控件可用键盘 Tab 聚焦后 Enter／空格操作。

## 收起与菜单
鼠标悬停显示右上角小「−」，点击只隐藏台灯，保留系统模式和屏幕滤色。顶部菜单「显示小台灯」恢复。
灯光四档统一通过灯具交互切换。顶部菜单提供换灯具、隐藏、重置位置、置顶、Chrome 检查、打开系统外观及退出。
右键灯具不再弹出原生菜单，避免之前的可疑崩溃路径。应用管理功能请使用顶部菜单，灯光模式在灯具上操作。灯具下方没有可见文字标签。

## 四档
| 档位 | 系统外观 | 屏幕效果 |
| --- | --- | --- |
| 日间 | 浅色 | 无额外滤色 |
| 暖光 | 浅色 | 暖色窗口覆盖层 |
| 夜读 | 深色 | 无额外滤色 |
| 微光 | 深色 | 较淡的黑色窗口覆盖层 |

暖光与微光不是硬件亮度／色温调节，也不意味着护眼等级。滤色窗口允许鼠标穿透；退出应用会移除滤色，系统浅／深色保留。重新启动默认使用当前系统外观，不自动恢复暖光或微光。

## Chrome 不跟随时
Chrome 普通新标签页 → 自定义 Chrome → 外观 → 设备。关闭旧小灯当家扩展并刷新网页。
在顶部菜单选「检查 Chrome 外观…」，查看系统读取值，并在 Chrome 检查页切换日间／夜读。若菜单打不开检查页，可在 Chrome 用 ⌘O 打开 src/ui/chrome-check.html。
https://support.google.com/chrome/answer/9275525?hl=zh-Hans

## 运行限制与报错
开发环境为 Linux，无法实测 macOS Cocoa/WebKit、授权弹窗和桌面窗口。29 项测试使用 API 替身，不等于 Mac 实测。需确认新灯具的实际布局、透明边缘、手势、窗口缩放及多屏／Spaces 行为。
本机生成并临时签名，未作 Apple 公证。安装失败请提供完整错误，启动失败可运行：
```bash
"$HOME/Applications/小灯当家.app/Contents/MacOS/applet"
```

0.5.1：吊灯视觉缩小 25%，顶部吸顶盘移到窗口外，只露出从上沿垂下的细吊线。吊灯拉绳、划动区、光晕和收起按钮一起调整位置。

0.5.2：移除顶部菜单中的日间、暖光、夜读、微光四项；四档模式仍可通过灯具交互切换。

0.5.3：菜单栏使用固定宽度，保持图标引用并显式显示。图标资源加载失败时显示「灯」，仍可打开菜单。

0.5.6：正式更名为「小灯当家」，安装时兼容旧版应用路径，保留原偏好设置。

## 移动灯具
按住灯身拖动。球灯或灯罩的触摸区用于换光时，请悬停后按住左上角「⠿」移动手柄拖动。拉绳仍用于换光。位置会自动记住，菜单「重置台灯位置」可恢复默认位置。
