# 小灯当家 · 首次公开测试

你的桌面，小灯当家。

## 这版可以做什么
- 十款灯具，支持旋钮、拉绳、滑动或滚轮换光。
- 日间、暖光、夜读、微光四档。
- 所有灯具可拖动，悬停出现移动和收起按钮，分别记住位置。
- Mac 菜单栏 / Windows 托盘管理灯具。

## 下载与启动
- **Mac 0.5.6**：下载 `小灯当家-Mac-v0.5.6-自由拖动版.zip`，完整解压，双击「安装小灯当家.command」。
- **Windows 0.1.3（x64）**：下载 `小灯当家-Windows-v0.1.3-自由拖动版.zip`，完整解压，双击「启动小灯当家.cmd」。如需桌面入口，运行「创建桌面快捷方式.cmd」。不要单独移动 exe。

## 测试版说明
52 项模拟测试通过，尚未完成完整实机验证。Windows 曾出现不透明滤层、任务栏文字异常；本版包含滤层透明度检查，但实机兼容性仍待确认。Mac / Windows 均未完成正式发行签名流程。

应用会修改系统外观；退出会移除滤层，但不会恢复原来的浅／深色设置。网站是否变色取决于其是否支持跟随系统。

如遇遮挡，退出小灯当家；如退出后任务栏显示异常，在系统颜色设置中重新切换外观。ICU data 启动错误请先重新完整解压。

请通过 Issues 反馈系统、版本、灯型、档位和复现步骤。
