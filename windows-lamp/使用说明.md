# 小灯当家 Windows 0.1.3 · 首版

适用于 Windows 10/11 的 x64 电脑。此包是首版试用构建，未在 Windows 实机验证。

## 打开
完整解压后双击 `小灯当家.exe`。请保留同目录下的全部文件，不要单独移动 exe。不需要安装 Node.js，也不需要管理员权限。

启动后右下角任务栏通知区域出现台灯图标，可能收在「^」里。点击或右键图标，打开灯具菜单。再次启动同一程序会显示现有小灯，不会重复创建。

## 灯具与交互
共十款：蘑菇灯、布罩灯、球形灯、花瓣吊灯、格纹吊灯、复古搪瓷吊灯、纸月灯笼、奶油飞碟吊灯、铃兰吊灯、折叶落地灯。名称没有编号或方向说明。

- 蘑菇灯：点小旋钮换档。
- 布罩灯、花瓣吊灯、复古搪瓷吊灯、铃兰吊灯、折叶落地灯：按住拉绳往下拉，松手换档。
- 球形灯、格纹吊灯、纸月灯笼、奶油飞碟吊灯：在灯罩上按住滑一下，或者滚动鼠标滚轮换档。
- 鼠标悬停出现小「−」，点击收起。托盘菜单「显示小台灯」恢复。
- 普通台灯和落地灯可拖动灯杆或底座；六款吊灯初始放在主屏右上角，也能拖动。每款灯具单独记忆位置。

托盘菜单可换灯具、显示／隐藏、重置位置、切换置顶、打开系统颜色设置、退出。菜单不展示四档灯光名称。

## 四档效果

| 档位 | Windows 应用与系统外观 | 屏幕滤色 |
| --- | --- | --- |
| 日间 | 浅色 | 无 |
| 暖光 | 浅色 | 约 13% 暖色覆盖 |
| 夜读 | 深色 | 无 |
| 微光 | 深色 | 约 23% 黑色覆盖 |

仅用户切换灯光时写入当前账户的应用与系统外观设置。首次打开读取当前外观。系统切换通过当前用户主题偏好和设置变更通知实现，部分应用不会立即响应。

暖光和微光使用允许鼠标穿透的覆盖窗口，不是硬件亮度或 Night light 色温。覆盖所有当前连接屏幕；屏幕配置变化后重新布局。独占全屏、锁屏与系统安全桌面不保证覆盖。退出会移除滤色，保留最后选择的系统浅／深色。

Chrome 请将「自定义 Chrome → 外观」设为跟随设备。只支持固定主题的网站不会被强制改色。四档不是护眼等级。

## 构建与验证边界
当前是未签名的便携测试构建。已验证核心逻辑及交互的 17 项模拟测试，尚未实测 Windows 的透明窗口、托盘、注册表切换和多屏效果。正式发布前需完成实机验证与代码签名。

源码包中的 `开发启动.cmd` 用于安装依赖并启动；`打包Windows.cmd` 生成 x64 便携目录，需要先安装 Node.js 22 或更高的受支持版本并联网。已锁定 Electron 与打包器版本。

实现参考：[Electron BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window)、[Windows 设置变更广播](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendmessagetimeoutw)。

0.1.1：正式更名为「小灯当家」，继续使用原偏好目录。升级时请先从旧版托盘菜单退出，再打开新版。

0.1.3：修复暖光覆盖层不透明的风险。改用六位 RGB 颜色和独立窗口透明度，暖光 13%、微光 23%，显示前读取验证；验证失败会撤掉覆盖层。19 项模拟测试通过，仍需 Windows 实机确认。

## 移动灯具
按住灯身拖动。球灯或灯罩的触摸区用于换光时，请悬停后按住左上角「⠿」移动手柄拖动。拉绳仍用于换光。位置会自动记住，菜单「重置台灯位置」可恢复默认位置。

## 启动与 debug 日志
完整解压后双击根目录「启动小灯当家.cmd」，不要将 exe 单独移出文件夹。若要桌面入口，双击「创建桌面快捷方式.cmd」。debug 是启动失败可能产生的日志；ICU data 错误通常表示 icudtl.dat 等运行文件缺失或无法读取。请重新完整解压并检查安全软件的隔离记录，不要关闭安全防护。启动入口会检查 exe、icudtl.dat、资源包和主要运行文件，缺失时提示重新解压。
