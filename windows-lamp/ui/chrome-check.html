Chrome 有没有收到外观变化？

保持此页打开，点击小灯在「日间」和「夜读」之间切换。此页背景和上面的文字应一起改变。暖光与日间都对应浅色，微光与夜读都对应深色；滤色不会改变下面检测到的主题值。

如果 Chrome 整体不变

  1. 在 Chrome 打开一个普通新标签页，点击右下角「自定义 Chrome」，在「外观」中选择「设备」。
  2. 关闭旧版小灯当家扩展并刷新本页。扩展可能改写背景，让检查结果难以判断。
  3. 打开 macOS「系统设置 → 外观」，确认小灯切换日间／夜读时，系统设置本身是否改变。

系统设置不变：回到小灯菜单，运行「检查 Chrome 外观」，查看系统读取结果或授权错误。系统设置变、本页主题文字不变：先确认 Chrome 选择了「设备」；保存工作后退出并重开 Chrome再测。本页文字和背景都变、其他网站不变：这些网站可能有自己的主题设置，或没有适配深色模式。

如果安装了第三方 Chrome 主题，可以在 Chrome 设置 → 外观检查主题；必要时手动恢复默认主题后重试。此工具不会自动改动你的主题、标签页或浏览记录。
